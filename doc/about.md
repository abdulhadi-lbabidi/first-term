# 🏨 Project Identity — Vercel Hotels

## اسم المشروع

**Vercel Hotels**

## نوع المشروع

منصة حجز إلكترونية لسلسلة فنادق فاخرة متعددة الفروع، تتيح للمستخدم استعراض الغرف، مقارنة الخيارات، اختيار التاريخ، الدفع، وإدارة الحجوزات.

## الرؤية (Vision)

تقديم تجربة حجز فندقية رقمية راقية تجمع بين:

* سهولة الاستخدام
* الفخامة
* السرعة
* الثقة
* تجربة شخصية لكل زائر

## الرسالة (Mission)

تحويل عملية حجز الفنادق من عملية تقليدية إلى تجربة رقمية سلسة تبدأ من اكتشاف الفندق وتنتهي بإقامة مريحة.

# UX Rules

1. لا يوجد أكثر من 3 خطوات للحجز.
2. الصور هي العنصر الأساسي.
3. السعر واضح دائماً.
4. المستخدم يعرف حالة الحجز دائماً.
5. RTL للعربية بشكل كامل.
