# Vercel Hotels 🏨

Welcome to **Vercel Hotels**, a modern, premium, and fully responsive hotel booking web application. Built with React, TypeScript, and Vite, it offers an exceptionally smooth user experience with high-end UI aesthetics, seamless filtering, and bilingual support (English/Arabic).

🌍 **Live Demo:** [https://vercel-hotels.vercel.app](https://vercel-hotels.vercel.app)

## 🌟 Features

- **Premium UI/UX:** Glassmorphism design, smooth micro-animations, and a highly polished aesthetic tailored for a luxury feel.
- **Bilingual Support:** Full Right-to-Left (RTL) Arabic and Left-to-Right (LTR) English layout switching.
- **Advanced Filtering:** Real-time filtering with responsive skeleton loading, smooth layout transitions, and no layout jumps.
- **Dark/Light Mode:** First-class dark mode support for nighttime browsing.
- **Local Storage Architecture:** Complete persistent mock backend simulating an actual database using browser `localStorage`.

## 🚀 Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom CSS Variables
- **Icons:** Lucide React
- **Routing:** React Router DOM

## ⚙️ Installation & Setup

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abdulhadi-lbabidi/first-term.git
   cd first-term
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed. It is recommended to use `pnpm` (though `npm` or `yarn` work too):
   ```bash
   pnpm install
   ```

3. **Start the development server:**
   ```bash
   pnpm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:5173` (or the port provided in your terminal) to view the application.

## 🛠 Available Scripts

- `pnpm run dev`: Starts the Vite development server.
- `pnpm run build`: Builds the app for production into the `dist` folder.
- `pnpm run preview`: Locally previews the production build.
